- The already-authorized global plugin/engine install and isolated runtime proof are complete as recorded above; the install and restart outcomes are user-reported, while the runtime proof is independently verified.
- The restart invocation itself returned `Command cancelled`; retain this outcome alongside the subsequent API check rather than describing the invocation as successful.
- Do not preflight or write global worker/advisor profiles; do not mutate the repository project's workflow state or make a model call.
- This feature does not authorize package-version edits, commits, pushes, tags, or npm publication. The separate 1.4.1 GitHub-only delivery plan and local unpublished 1.5.0 candidate remain pending.
- Use ADR-005 defaults: main thread at most 8k steady-state tokens; worker-code 8k, worker-verify 4k, and worker-debug 6k tokens per dispatch; 32k tokens and 15 minutes per run.
